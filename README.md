# axs2kilt

Automated [KRAI X](https://github.com/krai/axs) workflows for [KILT](https://github.com/krai/kilt-mlperf) (KRAI Inference Library Technology).

To import this repository and its dependencies into your **work_collection**, run:
```
axs byquery git_repo,collection,repo_name=axs2kilt
```
